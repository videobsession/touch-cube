# Touch Cube

A graphite metal cube you spin with your finger. It coasts to a stop depending on how hard you push, with a quiet wind-and-bearing sound.

**Install on iPhone:** open https://videobsession.github.io/touch-cube/ in Safari, tap Share, then **Add to Home Screen**. It opens full-screen and works offline.

Built with [three.js](https://threejs.org) r128 (MIT licence, included as `three.min.js`).
